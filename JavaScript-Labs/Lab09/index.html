BÀI THỰC HÀNH JAVASCRIPT / 09

DOM và Events

Khám phá cách JavaScript tương tác với các thành phần HTML và xử lý hành động của người dùng trên trang web.

01 / TỔNG QUAN

Những gì đã học

Bài thực hành giúp mình tìm hiểu cách JavaScript tương tác với tài liệu HTML thông qua mô hình Document Object Model (DOM). Qua đó, mình tiếp cận cách lựa chọn, truy cập và thay đổi các thành phần trên trang web, đồng thời tìm hiểu cách xử lý những tương tác của người dùng thông qua các sự kiện (Events).

02 / KIẾN THỨC TRỌNG TÂM

Các khái niệm đã tiếp cận

  • Tìm hiểu mô hình Document Object Model (DOM).
  • Lựa chọn và truy cập các phần tử HTML.
  • Thay đổi nội dung và thuộc tính của phần tử.
  • Điều chỉnh kiểu hiển thị và CSS class bằng JavaScript.
  • Xử lý sự kiện và tương tác của người dùng.
  • Làm việc với biểu mẫu (Forms) và dữ liệu đầu vào.

03 / KỸ NĂNG ĐẠT ĐƯỢC

Phát triển kỹ năng

Thông qua bài thực hành, mình có cơ hội vận dụng JavaScript để truy cập và thao tác với các phần tử HTML, xử lý sự kiện cũng như cập nhật nội dung trang web theo tương tác của người dùng. Qua đó, mình hiểu rõ hơn vai trò của DOM và Events trong việc xây dựng giao diện web có tính tương tác, góp phần cải thiện trải nghiệm người dùng.
