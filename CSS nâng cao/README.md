# Lab 07 - Advanced CSS: Layout

## 1. Giới thiệu

Lab 07 - Advanced CSS: Layout là bài thực hành về các kỹ thuật CSS nâng cao, tập trung vào việc xây dựng bố cục trang web, định vị phần tử, thiết kế giao diện responsive và tạo hiệu ứng chuyển động.

Người học được thực hành cách kiểm soát vị trí, kích thước, cách hiển thị và sự tương tác của các thành phần HTML bằng CSS.

## 2. Mục tiêu

- Hiểu cách trình duyệt sắp xếp các phần tử HTML trong Normal Document Flow.
- Sử dụng Positioning để định vị và sắp xếp các phần tử.
- Áp dụng Float và Clear để xây dựng bố cục trang web.
- Thiết kế layout hai cột và ba cột.
- Sử dụng Media Queries để xây dựng giao diện Responsive.
- Sử dụng CSS Transforms, Transitions và Filters.
- Tạo hiệu ứng chuyển động bằng CSS Animations.
- Làm quen với Bootstrap Grid System và các component có sẵn.

## 7. Kiến thức CSS đã thực hành

Các thuộc tính và kỹ thuật chính được sử dụng trong Lab 07:

| Chủ đề            | Thuộc tính / Kỹ thuật                                            |
| ----------------- | ---------------------------------------------------------------- |
| Display           | `display: block`, `inline`, `inline-block`, `none`               |
| Positioning       | `position`, `top`, `left`, `right`, `bottom`                     |
| Stacking          | `z-index`                                                        |
| Floating          | `float`, `clear`                                                 |
| Box Model         | `margin`, `padding`, `width`                                     |
| Responsive Design | `@media`, `min-width`, `max-width`                               |
| Viewport          | `meta viewport`                                                  |
| Transform         | `rotate()`, `scale()`, `translate()`, `skew()`                   |
| Transition        | `transition`, `:hover`                                           |
| Filter            | `grayscale()`, `contrast()`, `brightness()`, `blur()`, `sepia()` |
| Animation         | `@keyframes`, `animation`                                        |
| Bootstrap         | `container`, `row`, `col-md-*`                                   |
